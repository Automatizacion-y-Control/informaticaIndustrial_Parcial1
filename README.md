Proyecto integrador de infraestructura industrial: de servidores virtuales en
VMware (Windows Server y Ubuntu Server) a una base de datos administrada en
Amazon RDS, con su configuración de seguridad en AWS. Trabajo grupal para el
Parcial N° 1 de la cátedra Informática Industrial.

## Estructura del proyecto

Organizado en las cuatro fases del flujo de trabajo del grupo:

| Carpeta | Contenido |
|---|---|
| [`a_requisitos/`](a_requisitos/) | Consigna original (`PARCIAL Nº 1.pdf`), el Word fuente sin normalizar (`fuente/`) y `diseño.md`: el sistema de diseño editorial que rige la maquetación del informe. |
| [`b_investigacion/`](b_investigacion/) | Investigación de base previa a la resolución. |
| [`c_prototipado/`](c_prototipado/) | Informe fuente (`informeParcial1_infoInd.md`), las 55 capturas normalizadas (`assets/`) y el script (`scripts/build_pdf.py`) que compila todo a PDF respetando `diseño.md`. |
| [`d_presentacion/`](d_presentacion/) | Entregables finales: el informe en PDF y la presentación de defensa en PowerPoint. |

## Entregables finales

- 📄 [`informeParcial1_infoInd.pdf`](d_presentacion/informeParcial1_infoInd.pdf) — informe completo, generado a partir del Markdown fuente.
- 📊 [`Parcial_1_Informatica_Industrial_Defensa.pptx`](d_presentacion/Parcial_1_Informatica_Industrial_Defensa.pptx) — presentación de defensa oral.
